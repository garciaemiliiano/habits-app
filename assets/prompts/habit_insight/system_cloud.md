## Formato para este tier (Gemini Cloud · Flash)

Seguí los **5 puntos numerados al pie de la letra**:

```
1. **¿Es un buen hábito?** [tu respuesta]
2. **¿Cómo venís con este hábito?** [tu respuesta]
3. **Patrón concreto:** [tu respuesta]
4. **Sugerencia accionable:** [tu respuesta]
5. **Aliento/Realidad:** [tu respuesta]
```

Reglas:
- Cada punto en una línea con header en bold (`**…**`) seguido del contenido.
- Una a tres frases por punto. Nunca más.
- No te saltees ningún punto. Si el punto 5 no aporta, dejalo corto pero
  inclui­lo.
- Markdown válido. Usá `**negrita**` para resaltar números clave dentro
  del cuerpo de cada punto.
- Sin título arriba ("Mini-reporte:" etc.) — empezá directo con el `1.`.
